# MeteoritePlugin

Dynamic world event plugin for Minecraft Paper/Spigot. Spawns falling meteorites with custom particle trails, impact explosions, configurable loot tables, and protective mob waves.

## Features
- **Dynamic Meteor Spawning**: Scheduled or command-triggered meteor strikes across worlds.
- **Visual & Audio FX**: Custom particle trails, ambient impact sounds, and visual blast effects.
- **Custom Staff Item**: Staff of Meteorites allowing players to call down strikes in real-time.
- **Loot Table & Chest Generation**: Spawns reward chests at the impact site with configurable tiered loot.
- **Protected Zone Integration**: Safe checks to prevent griefing in spawn or claimed regions.

## Requirements
- Java: 17+
- Server: Paper / Purpur / Spigot 1.20+
